# Full Stack Bug & Defect Tracker

Full-stack ticket management web app.

**Tech Stack:** Java, Spring Boot, Angular, RxJS, PostgreSQL, Docker (in the process of migrating from H2)

## Instructions for running the program
Backend: 

Open a terminal with in the backend folder and run this:
`./mvnw spring-boot:run` 
Then open a new browser tab to localhost:8080.
If successful, should show "[]" which will be the tickets.

Frontend:
Open a terminal with in the frontend folder and run this:
`ng serve`
Then open a new browser tab to localhost:4200.
If successful, should show the option to create a ticket with dropdowns and textboxes.
